# TikTok Creator Toolkit

Offline-first Android creator toolkit. Package: com.creator.tiktoktoolkit.

Features: local idea/Hook/Caption/Hashtag tools, Room content organizer, local video metadata reader, teleprompter, local reminders, manual stats and engagement rate, Material 3, Arabic RTL default, no TikTok login/API/private-account access.

Build: open the android folder in Android Studio or run Gradle assembleDebug. GitHub Actions builds a Debug APK artifact on every change under android/.
